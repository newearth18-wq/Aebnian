# แอบเนียน · เกมซ่อนหาและตอบคำถาม

เกม 3D หลายผู้เล่นจากซอร์ส `meccha-chameleon-game-main.zip` ที่ผู้ใช้ให้มา พร้อมระบบข้อสอบสำหรับห้องเรียน ตัวเกมยังคงแผนที่ ตัวละคร ระบบระบายสี พลังพิเศษ ห้องเล่น WebSocket และ CodeQuest จากซอร์สเดิม

## การเล่น

1. เปิดหน้าเกม เลือกชุดคำถาม ใส่ชื่อ และสร้างหรือเข้าห้อง
2. ผู้สร้างห้องเลือกแผนที่และเริ่มรอบ ผู้ซ่อนระบายสีพรางตัว ผู้หาตามหา
3. กดปุ่มตอบคำถามในเกม ตอบถูกได้คะแนน พลังงาน และปลดล็อกสีใหม่
4. ชุด “ตัวอย่าง · ความรู้รอบตัว” มี 4 ข้อสำหรับทดลองเล่นทันที

### การบังคับ

- คอม: WASD หรือปุ่มลูกศรเดินตามภาพที่เห็น ลากเมาส์เพื่อมอง กด C หรือ “จัดกล้อง” เพื่อกลับมามองด้านหลังตัวละคร ปุ่ม WASD ใช้ได้แม้เลือกคีย์บอร์ดภาษาไทย
- มือถือ: แตะทิศบนจอยหรือลากบริเวณซ้ายล่างเพื่อเดิน ปัดฝั่งขวาเพื่อมอง หุบนิ้ว/กางนิ้วเพื่อซูม และกด “จัดกล้อง” เมื่อหลงทิศ
- ปล่อยปุ่มหรือจอยแล้วหยุดทันที จอยใกล้จุดกลางใช้เดินช้าเพื่อเข้าจุดซ่อน
- กด F หรือปุ่มทาสีเพื่อเปิดโหมดระบายสี กด Space เพื่อกระโดดและปีน

## สำหรับครู

ระหว่างเล่น กดปุ่ม “ท่าทาง” (คอมกด R ได้ด้วย) เพื่อเลือกยืน นั่ง นอน และท่าอื่น ๆ ได้ทั้งผู้หาและผู้ซ่อน เมื่อลากจอยเดินหรือกระโดดจะลุกจากท่านั่งอัตโนมัติ

ตอบคำถามแล้วจะแสดงเฉลยและคำอธิบาย 2 วินาที จากนั้นสุ่มข้อถัดไปจากชุดเดิม ตอบข้อเดิมซ้ำได้และได้คะแนน/พลังงานตามปกติ กด “กลับเข้าเกม” เพื่อหยุดตอบได้ทุกเวลา

เปิด `/admin` เพื่อสมัครหรือเข้าสู่ระบบด้วยอีเมล แล้วสร้างชุดข้อสอบ แก้ไขคำถามแบบ 4 ตัวเลือก ระบุเฉลย และกดเผยแพร่ นักเรียนจะเห็นเฉพาะชุดที่เผยแพร่แล้ว ครูแก้ไขได้เฉพาะชุดของบัญชีตนเองผ่าน Supabase Auth, Row Level Security และฟังก์ชันบันทึกแบบธุรกรรมเดียว

หากลืมรหัสผ่าน กด “ลืมรหัสผ่าน?” ที่หน้าครูหรือหน้าล็อกอินในเกม หรือเปิด `/reset-password` เพื่อขอลิงก์ทางอีเมล ตั้งรหัสผ่านใหม่อย่างน้อย 8 ตัวอักษรและยืนยันอีกครั้ง บัญชีที่ใช้ร่วมกับ Coastal Quest จะใช้รหัสใหม่เดียวกัน ต้องอนุญาต URL `https://aebnian-classroom-game.onrender.com/reset-password` ใน Supabase Auth → URL Configuration → Redirect URLs ด้วย

เกมใช้ฐานร่วม Frostbound Classroom โดยแยกตาราง Aebnian ด้วยชื่อ `aeb_` และใช้โปรเจกต์ Supabase ที่ระบุใน `supabase-public.json` (URL และ publishable key เป็นข้อมูลสาธารณะ) ห้ามใส่ service role key ในไฟล์นี้หรือฝั่ง client อ่านโครงสร้างฐานร่วมและสถานะการย้ายข้อมูลเก่าใน [supabase/SHARED_DATABASE.md](supabase/SHARED_DATABASE.md)

## รันในเครื่อง

ต้องใช้ Node.js 18 ขึ้นไป และ npm

```sh
cd server
npm install
npm start
```

เปิด `http://localhost:3000` สำหรับเกม และ `http://localhost:3000/admin` สำหรับครู เกมต้องเข้าผ่านเซิร์ฟเวอร์เพื่อใช้ WebSocket และ API ข้อสอบ

## โครงสร้าง

- `client/` — เกม 3D, ภาพโมเดล และหน้าเว็บครู
- `server/server.js`, `server/websocket.js` — ห้องเกมหลายผู้เล่นและคะแนน
- `server/supabase.js`, `server/questions.js` — ชุดข้อสอบที่เผยแพร่และตรวจคำตอบ
- `supabase/migrations/` — ตาราง สิทธิ์ และฟังก์ชันบันทึกข้อสอบ
- `render.yaml` — Render Blueprint สำหรับเกมและ CodeQuest
