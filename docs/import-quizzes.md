# นำเข้าข้อสอบสำหรับครู

เข้าสู่ระบบที่ `/admin` เลือกชุดเดิมหรือสร้างชุดใหม่ แล้วกด **นำเข้าข้อสอบ**

1. ดาวน์โหลดไฟล์ตัวอย่าง Excel, CSV, Word หรือ PDF จากหน้าครูหรือหน้าต่างนำเข้า
2. แก้ไขไฟล์แล้วเลือกไฟล์ หรือวางลิงก์ Google Sheets ที่อ่านผ่านลิงก์ได้
3. ตรวจคำถาม ตัวเลือก และเฉลยในหน้าตัวอย่าง แก้ไขหรือตัดข้อที่ไม่ต้องการออกได้
4. เลือกเพิ่มต่อท้ายหรือแทนที่คำถามในฟอร์ม แล้วกดเพิ่มเข้าฟอร์ม
5. ใส่ชื่อชุด แล้วกด **บันทึกชุดข้อสอบ** จึงจะบันทึกลงบัญชีครู ติ๊กเผยแพร่ด้วยหากต้องการเลือกตอนสร้างห้อง

ไฟล์ใน `client/templates/` ใช้ตัวอย่างเดียวกัน 3 ข้อ:

- `aebnian-quiz.xlsx`: Excel มีรายการเลือกเฉลย A–D รองรับเปิดใน Google Sheets
- `aebnian-quiz.csv`: UTF-8 พร้อม BOM สำหรับ Excel / Sheets
- `aebnian-quiz.docx`: Word แบบข้อความเรียงข้อ
- `aebnian-quiz.pdf`: PDF ที่เลือกคัดลอกข้อความได้

## รูปแบบตาราง

หนึ่งแถวต่อข้อ ใช้หัวคอลัมน์ `คำถาม, A, B, C, D, เฉลย, คำอธิบาย` คำอธิบายเว้นได้ เฉลยใช้ A–D, ก–ง หรือ 1–4 ระบบรองรับหัวคอลัมน์ภาษาอังกฤษด้วย หากใช้ `correct_option` ตัวเลขหมายถึง 0–3 โดยเฉพาะ ไฟล์หลายแท็บมีตัวเลือกแท็บก่อนนำเข้า

Google Sheets ใช้ URL ของแท็บที่ต้องการ (`gid`) ได้ ทั้งลิงก์ปกติที่อ่านได้และลิงก์เผยแพร่ หากเป็นชีตส่วนตัว ให้ดาวน์โหลดเป็น CSV หรือ Excel แล้วเลือกไฟล์ ไม่จำเป็นต้องเปลี่ยนสิทธิ์แชร์ ระบบตรวจบัญชีครูก่อนอ่านลิงก์ และไม่ส่งโทเคนบัญชีไปที่ Google

## รูปแบบ Word / PDF / ข้อความ

```text
1. น้ำมีสูตรเคมีข้อใด?
A. CO₂
B. O₂
C. H₂O
D. NaCl
เฉลย: C
คำอธิบาย: น้ำมีสูตร H₂O
```

Word รองรับ `.docx` และตารางที่มีหัวคอลัมน์ตามตัวอย่าง PDF รองรับข้อความที่เลือกคัดลอกได้ ไม่มี OCR สำหรับภาพสแกน เอกสารที่จัดหน้าเป็นหลายคอลัมน์อาจต้องแก้ข้อความที่อ่านได้ก่อนแยกข้อสอบ ระบบไม่เดาเฉลยที่ขาดหายหรือไม่รู้จัก ต้องเลือกให้ครบก่อนเพิ่มเข้าฟอร์ม

จำกัดไฟล์ 10 MB, PDF 50 หน้า, ข้อสอบรวม 100 ข้อต่อชุด ตารางอ่านได้ไม่เกิน 1,000 แถว และข้อความเอกสาร 200,000 ตัวอักษร เกินขีดจำกัดจะแจ้งให้แบ่งไฟล์ ไม่ตัดคำถามทิ้งเงียบ ๆ

ไฟล์ที่อัปโหลดอ่านในเบราว์เซอร์ เอกสารต้นฉบับไม่ถูกส่งเข้าเซิร์ฟเวอร์เกม ข้อมูลที่บันทึกคือคำถามที่ครูตรวจแล้วผ่านสิทธิ์ฐานข้อมูลเดิมของบัญชีตนเอง
