# Chroma Hide 3D

เกมซ่อนหา 3D ในเบราว์เซอร์ซึ่งได้แรงบันดาลใจจากวิดีโอ MECCHA CHAMELEON ที่ผู้ใช้ส่งมา ตัวละครและฉากสร้างขึ้นใหม่ทั้งหมด ไม่ได้ใช้ไฟล์ต้นฉบับของเกม

## เล่น

เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ HTTP (ES modules ไม่ทำงานบน `file://`) เช่น `python -m http.server 8000` แล้วเข้า `http://localhost:8000` หรือใช้ลิงก์ที่เผยแพร่ไว้

- เลือกแผนที่ Backrooms, Toy Room หรือ Pool และเลือกบทบาทผู้ซ่อนหรือผู้หา
- WASD/ลูกศร: เดิน, Shift: วิ่ง, ลากเมาส์: หมุนกล้อง
- ผู้ซ่อน: E เปิดระบายสี, คลิกส่วนร่างกายเพื่อแต้ม, ดูดสีจากฉาก, R เปลี่ยนท่า, T ส่งเสียงล่อ
- ผู้หา: คลิกเพื่อยิงผู้ซ่อน ยิงพลาดครบ 5 ครั้งจะแพ้
- ผู้ซ่อนที่ถูกจับ รวมถึงตัวผู้เล่น จะกลายเป็นผู้หาและเล่นต่อ (Infection)

เกมนี้เล่นคนเดียวร่วมกับคู่แข่ง AI ยังไม่มีระบบเล่นออนไลน์หลายคนหรือสินทรัพย์กราฟิกของเกมต้นฉบับ

## โครงสร้าง

- `index.html` — หน้าจอและส่วนควบคุม
- `style.css` — HUD และเมนู
- `game.js` — ฉาก 3D เกมลูป การเดิน AI และกติกา
- `vendor/three.module.js`, `vendor/three.core.js` — Three.js r186 ภายใต้สัญญาอนุญาต MIT; ดู `vendor/LICENSE-three.txt`
